IMPLEMENTATION
UI/WheelEffects.lua owns the decorative textures, state colours and clock.
UI/Wheel.lua owns input and opening/closing. Normal close stops mouse input before
the visual tail; combat entry interrupts both opening and closing synchronously.
Reopening cancels the current close without a delayed callback. All portrait
loads are cancelled on final cleanup. No protected frame moves or scales.

Art: python Tools/make_wheel_art.py (existing Pillow/numpy environment).
The sculpted crest source is Tools/Art/Crest/crest-fel-v2.png, created with the
built-in image_gen tool; its exact prompt is beside it in prompt.txt. The
generator preserves alpha and converts it to TGA. Other layers are procedural.
12 deterministic, uncompressed bottom-origin RGBA TGAs, 6.39 MiB total.
The opaque node band covers radius 0.70 through 0.98 to hide model corners.
Never hand-edit a generated TGA. The old Bead_ assets/generator remain available
but are no longer the wheel's material. No LibGlass changes or new dependencies.

TUNING
Open: 0.58 s; clockwise node delays 0.035 s; hover 0.16 s in / 0.24 s out.
Hover grows each visual by 12%, inspired by PortalRoulette's HearthOrb. The
portrait, opaque masking band and labels scale together; the button stays put.
Close: 0.30 s; active pulse: 2.8 s. Three smoke/flame layers: 47/-39/61 s turns.
Smoke/flame base alphas: 0.30/0.40/0.26; runes and node lighting stay distinct.
Outer runes: Portal Roulette's four-degree sway, 2 s out / 2 s back, eased
at both ends. Only the rune texture turns; the outer rim and nodes stay fixed.
14 staggered falling embers on a 2.6 s cycle, each with a small impact glow.
Frame states: normal green; active bright fel; unlearned grey; missing reagent
red; sacrificed violet (rendering only, awaiting #20's measured state).
